# Sobrevivência Jurássica

Jogo feito em Java (Swing) para o trabalho de POO. O jogador precisa sobreviver em um mapa cheio de dinossauros, usando itens que encontra pelo caminho.

## Como rodar

Abra o projeto na IDE e execute a classe `controle.Main`. No menu do terminal dá pra começar um jogo novo ou carregar um save.

Requisito: JDK 8+.

## Estrutura

- `controle/` — Main, tabuleiro e telas do jogo
- `pacoteBase/dinossauros/` — os dinossauros (T-Rex, Velociraptor, Troodonte, Compsognato)
- `pacoteBase/item/` — itens e armas
- `pacoteBase/jogador/` — o jogador
- `imagens/` — sprites
- `mapa01.txt`, `mapa02.txt`, `mapa03.txt` — mapas do jogo

# Jurassic Survival

Java (Swing) game made for our OOP class project. The player has to survive on a map full of dinosaurs, using items found along the way.

## How to run

Open the project in your IDE and run the `controle.Main` class. From the terminal menu you can start a new game or load a save.

Requires: JDK 8+.

## Structure

- `controle/` — Main, board and game screens
- `pacoteBase/dinossauros/` — the dinosaurs (T-Rex, Velociraptor, Troodon, Compsognathus)
- `pacoteBase/item/` — items and weapons
- `pacoteBase/jogador/` — the player
- `imagens/` — sprites
- `mapa01.txt`, `mapa02.txt`, `mapa03.txt` — game maps
